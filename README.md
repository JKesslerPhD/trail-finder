# Trail Finder

A single-file web tool that matches long-distance trails to what you actually have: your experience level, the number of days you can get away, the season you can travel, and the kind of country you want to walk through. It covers 79 trails, including all 11 National Scenic Trails, plus lesser-known routes and a solid international selection.

Live version: <https://trailpeaches.com/trail-finder/>

## How the matching works

- **Days available** is the strongest signal. The tool estimates how long you would take: base miles per day from your experience level, adjusted for how much of the route is well-signed versus route-finding or off-trail. That estimate is held inside the trail's real-world range, because published itineraries already account for elevation gain, hut stages, altitude and resupply that raw mileage cannot see. If a trail needs far more time than you have, it drops out. With partial time it shows up flagged as a section hike.
- **Season** is a hard filter. A trail that is not realistically hikeable in any month you selected will not appear.
- **Experience, region, terrain, remoteness, permits and guide coverage** shift the ranking rather than excluding trails, so you can see near-misses.

Everything runs in the browser. There is no server, build step or dependency.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## The trail data

The trails are a plain JavaScript array, `T`, near the top of the script in `index.html`. One entry looks like this:

```js
{ id:'pct', name:'Pacific Crest Trail', abbr:'PCT', mi:2653, st:'CA · OR · WA',
  reg:['pacific','northwest'],   // regions
  mind:120, maxd:180,            // realistic range of days for a thru-hike
  mo:[4,5,6,7,8,9],              // months it is realistically hikeable
  exp:4,                         // experience needed (1 to 4)
  rt:'linear', perm:true, lot:true, crowd:3, res:'moderate',
  ter:['alpine','forest','desert'], farout:true, nav:2,
  hook:'One-line description shown on the card.',
  caltopo_u:'https://caltopo.com/m/7G155HC' }
```

To add a trail, add an entry. The data is compiled from trail organizations and land managers, and it has not been verified trail by trail. Distances, seasons and permits change, so confirm current conditions with the managing agency before a trip.

## AI and data disclosure

Generative AI was used to help write most of the code developed to create this front end tool. Data were assembled, cleaned, processed, and verified directly before incorporating them into this tool, and were not generated by an LLM. This tool works differently from LLM-generated text. Results and calculations displayed by this tool are directly calculated using hard-coded methods and a fixed, underlying data set. As such, these results are not subject to hallucination, and remain repeatable. Accuracy of displayed results depends on the reliability and accuracy of the underlying data and methods that are used.

The same text appears in a pop-up inside the tool.
